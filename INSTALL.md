# Guía de Instalación para Kalendar 📦

Este archivo contiene los pasos detallados para configurar el proyecto **Kalendar** en tu entorno local.

## Requisitos Previos ⚙️

Asegúrate de tener lo siguiente instalado en tu máquina:

- **PHP** 8.2 o superior
- **Composer** (para gestionar las dependencias de PHP)
- **Node.js** (para el frontend)
- **pnpm** (como gestor de paquetes para el frontend)
- **PostgreSQL** (como base de datos)
